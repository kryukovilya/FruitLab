# Запуск и редактирование FruitLab

## Готовая игра

1. Откройте [последний релиз](https://github.com/kryukovilya/FruitLab/releases/latest).
2. Скачайте `FruitLab.exe` на компьютер с Windows x64.
3. Запустите файл и следуйте окнам распаковки и запуска. Сборка включает среду выполнения Varwin.

FruitLab разработан для взаимодействия в VR. Для проверки VR-управления нужен совместимый шлем с контроллерами. Минимальные аппаратные требования и работа без шлема отдельно не проверены.

Контрольные суммы опубликованы в `SHA256SUMS.txt`. Проверить скачанный файл в PowerShell можно командой:

```powershell
Get-FileHash -Algorithm SHA256 .\FruitLab.exe
```

## Проект в Varwin

1. Установите Varwin XRMS. Исходная версия экспорта — **18.2.170**.
2. Скачайте `FruitLab.vwp` из того же релиза.
3. В разделе «Проекты» выберите импорт и укажите `.vwp`.
4. Откройте импортированный проект. В нём сохранены сцены `Space`, `FruitLab` и `Claud`, объекты и игровые ресурсы.

Импорт в более новую версию может потребовать штатной миграции Varwin. Перед миграцией сохраните копию файла. Совместимость с конкретной установленной версией необходимо проверять при импорте.

Описание форматов и действий импорта: [документация Varwin](https://docs.varwin.com/18/ru/import-i-eksport-2275542044.html).

## Исходники

- `src/Objects` — девять C#-компонентов с prefab, asmdef и метаданными Unity.
- `src/scene-logic` — сгенерированная Varwin логика трёх сцен.
- `.vwp` в релизе — экспорт проекта с объектами, шаблонами сцен и ресурсами, включая платформенные пакеты исходного экспорта.

Для изменения C#-объектов требуется соответствующее окружение Unity и Varwin SDK. Репозиторий не является самостоятельным Unity-проектом: исходная папка Unity и авторские `.shader`/`.shadergraph` в доступных материалах отсутствуют.

## Подготовка дистрибутива

Готовые EXE и VWP хранятся в Releases. Скрипт `scripts/prepare_release.py` использует опубликованную командой сборку с официальной страницы Varwin, проверяет её SHA-256 и собирает полный экспорт из записанного состава ресурсов. Дополнительные платформенные ресурсы хранятся в `distribution/resources`.

```sh
python -m pip install -r distribution/requirements.txt
python scripts/prepare_release.py --output dist-release
```

Из зашифрованных метаданных лицензии удаляются имя, email и организация. Идентификатор, редакция и срок действия лицензии сохраняются. Скрипт проверяет эти условия и соответствие игровых файлов исходным данным; права использования движка и сторонних ресурсов сохраняются за их правообладателями.

В `verification.json` указываются результаты проверки архивов. Интерактивный запуск подготовленной сборки, прохождение игры и импорт в Varwin этой проверкой не подтверждаются.
